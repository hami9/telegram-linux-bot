# My Gateway for WooCommerce

درگاه پرداخت حرفه‌ای، امن و ماژولار برای ووکامرس — با معماری کاملاً شیءگرا (OOP)، استاندارد PSR-4، لاگ پیشرفته Monolog با تاریخ شمسی و مکانیزم Webhook برای تایید خودکار تراکنش‌ها.

## 📁 ساختار پروژه

```
my-gateway-for-woocommerce/
├── composer.json                  ← تنظیمات Autoloading (PSR-4) و وابستگی‌ها
├── index.php                      ← فایل اصلی ثبت پلاگین و لودر کامپوزر
└── src/
    ├── init.php                   ← راه‌اندازی اولیه و مدیریت هوک‌ها
    ├── Logger.php                 ← سیستم لاگ هوشمند (Monolog + تاریخ شمسی)
    ├── Drivers/
    │   ├── BaseDriver.php         ← کلاس انتزاعی درایورها (HTTP، امضا، نرمال‌سازی مبلغ)
    │   └── MyGatewayDriver.php    ← اتصال به API درگاه (Request / Verify / Inquiry / Webhook)
    └── Operators/
        └── Woocommerce/
            ├── Operator.php       ← کلاس اصلی درگاه (WC_Payment_Gateway)
            ├── Attach.php         ← اتصال به فیلترها و اکشن‌های ووکامرس
            ├── Requirements.php   ← بررسی پیش‌نیازها (PHP، ووکامرس، واحد پولی)
            ├── Block/
            │   ├── PaymentMethodBlock.php   ← سازگاری با Checkout بلوکی (Gutenberg)
            │   └── assets/payment-method.js ← کامپوننت فرانت‌اند متد پرداخت
            └── templates/
                ├── payment-form.php   ← قالب نمایش درگاه در تسویه‌حساب (قابل Override در پوسته)
                └── redirect-form.php  ← فرم انتقال خودکار به بانک (حالت POST)
```

## 🚀 نصب

1. پوشه افزونه را در `wp-content/plugins/` قرار دهید.
2. داخل پوشه افزونه وابستگی‌ها را نصب کنید:

   ```bash
   composer install --no-dev --optimize-autoloader
   ```

3. افزونه را از پیشخوان وردپرس فعال کنید.
4. از مسیر **ووکامرس ← تنظیمات ← پرداخت‌ها ← درگاه My Gateway** شناسه پذیرنده، کلید API و کلید Webhook را وارد کنید.
5. آدرس Webhook نمایش‌داده‌شده در صفحه تنظیمات را در پنل درگاه خود ثبت کنید.

## 🔐 ویژگی‌های امنیتی

- **توکن امنیتی یک‌بارمصرف در Callback**: نسخه خام در آدرس بازگشت و فقط هش آن در دیتابیس؛ مقایسه زمان-ثابت (`hash_equals`) در برابر Timing Attack و ابطال توکن پس از استفاده (ضد Replay).
- **امضای HMAC-SHA256** برای درخواست‌های API و صحت‌سنجی Webhook (Anti-Spoofing).
- **کنترل تطابق مبلغ** تراکنش با سفارش (ضد دست‌کاری مبلغ).
- **هدرهای امنیتی** در مسیرهای بازگشت و وبهوک (`X-Frame-Options`، `nosniff`، `Referrer-Policy`، `no-cache`).
- **قفل هم‌زمانی (Lock)** برای جلوگیری از شرایط رقابتی بین Callback و Webhook.
- **پوشه لاگ محافظت‌شده** با `.htaccess` و نام فایل هش‌شده غیرقابل حدس.

## 🔄 مکانیزم Webhook

اگر مشتری پس از پرداخت صفحه بانک را ببندد و به سایت برنگردد، بانک آدرس Webhook را با امضای HMAC صدا می‌زند؛ افزونه پس از صحت‌سنجی امضا، وضعیت تراکنش را **مستقیماً از بانک استعلام** کرده و در صورت پرداخت، سفارش را به‌صورت خودکار تکمیل می‌کند (Idempotent و امن در برابر payload جعلی).

## 📝 سیستم لاگ

تمام رخدادها (خطاها، رفتار کاربر، کدهای پاسخ بانک) با **Monolog** و **تاریخ شمسی** (کتابخانه `sallar/jdatetime`) در فایل چرخشی روزانه ثبت می‌شوند:

```
wp-content/uploads/my-gateway-logs/my-gateway-{hash}-YYYY-MM-DD.log
```

## 🧩 اتصال به درگاه واقعی

برای اتصال به هر PSP واقعی (زرین‌پال، زیبال، به‌پرداخت، سداد و ...) کافی است در `src/Drivers/MyGatewayDriver.php` آدرس Endpoint ها و نگاشت فیلدهای پاسخ را مطابق مستندات همان درگاه تغییر دهید — یا یک درایور جدید از `BaseDriver` مشتق کنید؛ بقیه معماری بدون تغییر کار می‌کند.
